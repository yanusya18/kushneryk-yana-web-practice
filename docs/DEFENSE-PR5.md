# Підготовка до захисту ПР 5

## Контрольні питання
**1. Коли доцільніший Flexbox, а коли — Grid?**
Flexbox — одновимірний (рядок *або* стовпець): шапка й навігація, ряд кнопок, вирівнювання вмісту
картки. Grid — двовимірний (рядки *і* стовпці): сітка карток, двоколонкова сторінка «контент + aside».
У проєкті: `.site-header__inner` і `.nav-list` — Flexbox; `.card-grid`, `.page-with-aside` — Grid.

**2. Як обчислюється специфічність селекторів?**
Рахується як трійка (a, b, c): a — кількість id, b — класи, атрибути й псевдокласи, c — теги й
псевдоелементи. Порівнюється по порядку. Приклад із проєкту: `.nav-list a[aria-current="page"]` = (0, 2, 1):
клас + атрибут + тег `a`. `!important` і inline-стилі вищі. За рівної специфічності перемагає пізніший запис.

**3. Чим mobile-first відрізняється від desktop-first на рівні коду?**
Mobile-first: базові стилі — для вузького екрана (360 px), а розширення додаються медіа-запитами
`@media (min-width: 768px)` і `(min-width: 1280px)`. Desktop-first навпаки: базові стилі для великого екрана,
а звуження — через `max-width`. Mobile-first дає менше перевизначень і легший CSS для телефонів.

**4. Які переваги й недоліки utility-first підходу Tailwind?**
Переваги: швидкість, єдина система значень, не треба вигадувати класи, у збірку потрапляє лише
використаний CSS. Недоліки: довгі класи в HTML, залежність від збірки, крива навчання. Деталі — `docs/CSS-VS-TAILWIND.md`.

## Пояснення ключових фрагментів
- **Токени:** `:root { --color-primary: var(--primary-600); }` — компоненти беруть `var(--color-primary)`.
  Темна тема лише перевизначає змінні.
- **Тема:** `@media (prefers-color-scheme: dark) { :root:not([data-theme="light"]) { … } }` + `:root[data-theme="dark"] { … }`.
- **Сітка:** `grid-template-columns: repeat(auto-fill, minmax(min(100%, 17rem), 1fr))` — стільки колонок по 17rem+, скільки влізе.
- **Адаптивні шрифти:** `clamp(1.75rem, 1.2rem + 2.5vw, 3rem)` — мінімум, плавне значення, максимум.
- **Фокус:** `:focus-visible` показує рамку лише при керуванні клавіатурою.
- **Анімації:** `@media (prefers-reduced-motion: reduce)` скорочує transition до майже нуля.
- **Валідація:** `input:user-invalid` підсвічує поле лише після взаємодії користувача.
