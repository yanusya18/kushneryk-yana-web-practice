# Що здати й зафіксувати (ПР 6)

Методичка вимагає: **JS-модулі в репозиторії; відео або GIF до 1 хв; скриншот вкладки Network із запитом до API.** Їх потрібно зробити вам — я не можу їх створити за вас.

## 1. GIF / відео (до 1 хв)
Запишіть екран (Windows: `Win+G`, ScreenToGif; Mac: `Shift+Cmd+5`). Покажіть по порядку:
1. Каталог: пошук (з паузою — працює debounce), тип, ціна, сортування, «Нічого не знайдено» → «Скинути фільтри».
2. `catalog.html?demo=loading` і `?demo=error` → «Спробувати ще раз».
3. Клік по картці → сторінка місця.
4. Бронювання: помилки валідації → зайнятий час → вільний час → модальне вікно → Esc.
5. Тема (перемикач + збереження після оновлення) і бургер-меню на 360 px.
Збережіть як `docs/screenshots/pr6-demo.gif` (або mp4).

## 2. Скриншот Network
1. `F12` → вкладка **Network** → фільтр **Fetch/XHR**.
2. Оновіть `catalog.html` — з'явиться запит `workspaces.json` зі статусом **200**.
3. Клацніть на запит → скриншот із вкладками *Headers* і *Response*.
Збережіть як `docs/screenshots/pr6-network.png`.
