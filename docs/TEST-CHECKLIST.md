# Чек-лист ручного тестування (ПР 9)

Запускайте `npm run dev` (або `npm run preview` після `npm run build`). Колонки **Фактичний результат** і **Статус** заповнюєте ви під час проходження (✅ пройдено / ❌ дефект → створіть Issue).

|---|---|---|---|---|---|
