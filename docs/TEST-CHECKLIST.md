# Чек-лист ручного тестування (ПР 9)

**Перед тестуванням запустіть API:** `cd server && npm run dev` (порт 3001), потім клієнт: `cd client && npm run dev` (або `npm run preview` після `npm run build`). Якщо хочете чисті демо-дані — `npm run reset-db` у `server/`. Колонки **Фактичний результат** і **Статус** заповнюєте ви під час проходження (✅ пройдено / ❌ дефект — опишіть його в `docs/AUDIT.md`, розділ 6).
