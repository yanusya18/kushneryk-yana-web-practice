## Підготовка
1. Запустіть сервер: `cd server`, `npm install`, `cp .env.example .env`, `npm run dev` → `http://localhost:3001`.
2. Перевірте в браузері: `http://localhost:3001/api/health` → `{"status":"ok"}`.

## Postman
1. Встановіть [Postman](https://www.postman.com/downloads/) (достатньо безкоштовного акаунта).
2. **Import** → оберіть `coworking-api.postman_collection.json`.
3. Змінна `baseUrl` уже задана в колекції (`http://localhost:3001`).
4. **Запуск усієї колекції:** наведіть на колекцію → **Run** → **Run Coworking API**. Усі тести мають бути зеленими.
5. **Окремі запити:** відкрийте запит → **Send** → вкладка **Test Results** показує результат перевірок.
6. Скриншот Runner (усі запити пройдені) → збережіть у `docs/screenshots/postman-run.png`.
7. **Експорт власної колекції** (якщо додасте запити): колекція → **…** → **Export** → Collection v2.1 → збережіть у `docs/postman/`.

Порядок запитів важливий: №6 створює місце й зберігає його `id` у змінну, №8–10 цю змінну використовують.
Запит №12 сам підставляє випадкову майбутню дату, щоб повторні запуски не конфліктували.

## Thunder Client (розширення VS Code)
1. Встановіть розширення **Thunder Client**.
2. Вкладка **Collections** → **…** → **Import** → оберіть той самий JSON-файл.
3. Запускайте запити по черзі. Змінні `{{baseUrl}}`, `{{createdId}}`, `{{bookDate}}` Thunder Client підтримує; якщо тести в
   безкоштовній версії обмежені, перевіряйте статус-код вручну за таблицею в `docs/API.md`.

## Що перевірити вручну (і показати викладачу)
| Дія | Очікування |
|---|---|
| `GET /api/items` | 200, масив місць |
| `POST /api/items` з порожнім `name` | 400 і перелік `errors` |
| `POST /api/bookings` двічі на той самий час | перший 201, другий 409 |
| `DELETE /api/items/1` | 409 (є майбутні бронювання) |
| `GET /api/nope` | 404 у форматі JSON |
| Зламаний JSON у тілі | 400 |
