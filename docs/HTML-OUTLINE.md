# Outline (контур документа) головної сторінки

Схема ієрархії заголовків `client/static/index.html`. Один `h1`, рівні без пропусків (1 → 2 → 3).

```
h1  Коворкінг, де зручно працювати
  h2  Чому обирають наш коворкінг
    h3  Природне світло
    h3  Швидкий інтернет
    h3  Гнучкі умови
  h2  Популярні місця
    h3  Місце A1 — біля вікна
    h3  Місце A2 — тиха зона
    h3  Місце B1 — із монітором
  h2  Як забронювати місце
  h2  Послуги та ціни
  h2  Години роботи
```

Перевірити самій: https://validator.w3.org/nu/ → вкладка **Check by file upload** → позначте **Show outline** → Check.
Зробіть скриншот outline для здачі (`docs/screenshots/outline-index.png`).
