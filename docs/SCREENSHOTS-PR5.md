# Скриншоти та перевірка верстки (ПР 5)

Методичка вимагає **скриншоти на 3 ширинах у світлій і темній темах**, перевірку в DevTools Device Mode
та в Chrome + Firefox. Зробіть їх самі у своєму браузері й покладіть у `docs/screenshots/`.

## Як зробити скриншот на потрібній ширині (Chrome)
1. Відкрийте сторінку (наприклад, `client/static/index.html` через Live Server).
2. `F12` → іконка пристроїв (`Ctrl+Shift+M`) → режим **Responsive**.
3. Введіть ширину **360**, потім **768**, потім **1280** (поле Width зверху).
4. Повний скриншот: `Ctrl+Shift+P` → введіть `screenshot` → **Capture full size screenshot**.

## Як перемкнути тему
- **Через ОС / DevTools:** `Ctrl+Shift+P` → `Render` → **Show Rendering** → поле
  **Emulate CSS media feature prefers-color-scheme** → `dark` або `light`.
- **Через атрибут:** вкладка Elements → клацніть на `<html>` → `F2`/«Edit attribute» → додайте
  `data-theme="dark"` (або `light`).

## Які файли зберегти (мінімум — головна й каталог; бажано всі сторінки)
Назви у форматі `<сторінка>-<ширина>-<тема>.png`:

- [ ] `index-360-light.png`, `index-768-light.png`, `index-1280-light.png`
- [ ] `index-360-dark.png`, `index-768-dark.png`, `index-1280-dark.png`
- [ ] те саме для `catalog`, `workspace`, `contacts` (за вимогою викладача)
- [ ] `contacts-tailwind-768-light.png` (порівняння з чистим CSS)

## Перевірка за макетом (pixel perfect ±4 px)
Макетів Figma (ПР 3) наразі немає, тому порівняти нема з чим. Після ПР 3 накладіть макет на
скриншот і перевірте відступи й розміри в межах ±4 px. Це **ваша дія**, я її не виконувала.

## Чек-лист ручної перевірки
| Перевірка | Chrome | Firefox |
|---|---|---|
| Немає горизонтального скролу на 360 / 768 / 1280 | ☐ | ☐ |
| Картки каталогу перебудовуються в 1 → 2 → 3 колонки | ☐ | ☐ |
| Hover на кнопках, картках, посиланні меню | ☐ | ☐ |
| `Tab`: видно рамку фокуса (`:focus-visible`) | ☐ | ☐ |
| Невалідне поле форми підсвічується червоним після введення | ☐ | ☐ |
| Темна тема: від ОС і через `data-theme` | ☐ | ☐ |
| `prefers-reduced-motion: reduce` вимикає анімації (Rendering → Emulate) | ☐ | ☐ |
| Кнопка `disabled` виглядає неактивною (у DevTools додайте атрибут `disabled`) | ☐ | ☐ |

> Мапа на сторінці контактів завантажується з інтернету (OpenStreetMap); без мережі вона порожня.
