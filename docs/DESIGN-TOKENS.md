# Дизайн-токени (ПР 5)

Токени оголошено у `client/assets/css/tokens.css` як CSS custom properties.
Дві рівні: **примітиви** (сирі значення) і **семантичні токени** (`--color-bg`, `--color-text` …),
які різняться між темами. Компоненти використовують лише семантичні токени, тому тема перемикається
зміною змінних, а не переписуванням стилів.

> ⚠️ Токени взято з моєї палітри за замовчуванням, **не з вашого Figma** (ПР 3 ще не виконана).
> Після ПР 3 звірте кольори, шрифт, відступи й радіуси з Figma Variables і оновіть `tokens.css`
> (достатньо змінити значення примітивів).

## Відступи і радіуси
| Токен | Значення | px |
|---|---|---|
| `--space-1` … `--space-6` | 0.25 / 0.5 / 1 / 1.5 / 2 / 3 rem | 4 / 8 / 16 / 24 / 32 / 48 |
| `--radius-sm / md / lg / full` | 0.375 / 0.75 / 1.25 rem / 999px | 6 / 12 / 20 / — |

## Типографіка (rem + clamp)
| Токен | Значення |
|---|---|
| `--fs-h1` | `clamp(1.75rem, 1.2rem + 2.5vw, 3rem)` |
| `--fs-h2` | `clamp(1.375rem, 1.1rem + 1.2vw, 2rem)` |
| `--fs-h3` | `clamp(1.125rem, 1.05rem + 0.4vw, 1.375rem)` |
| `--fs-h4`, `--fs-body`, `--fs-small` | 1.125rem, 1rem, 0.875rem |
| `--font-sans` | `"Inter", system-ui, …` — Inter підключіть через Google Fonts після ПР 3 (інакше працює системний шрифт) |

`clamp(мін, бажане, макс)` плавно змінює розмір між мінімумом і максимумом залежно від ширини екрана.

## Теми
| Спосіб | Як працює |
|---|---|
| За замовчуванням | Світла тема в `:root` |
| `prefers-color-scheme: dark` | Темна, якщо в ОС увімкнено темну тему і на `<html>` немає `data-theme="light"` |
| `<html data-theme="dark">` | Примусово темна (перекриває ОС) |
| `<html data-theme="light">` | Примусово світла (перекриває ОС) |

Перевірено в браузері: усі чотири комбінації (ОС × атрибут) дають очікуваний фон.
Кнопка-перемикач із збереженням у `localStorage` — це ПР 6.
