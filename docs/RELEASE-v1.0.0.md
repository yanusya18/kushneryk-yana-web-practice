# Простір v1.0.0 — сайт коворкінгу

Перший повноцінний випуск: сайт коворкінгу з онлайн-бронюванням робочих місць на конкретну дату й час.

## Можливості
- **Каталог** робочих місць: пошук, фільтр за типом і ціною, сортування, стани завантаження/помилки/порожнього списку.
- **Сторінка місця** (`/items/:id`): фото, обладнання, ціна, зайняті години на обрану дату.
- **Бронювання** на дату й час: валідація форми, перевірка доступності, підрахунок вартості, підтвердження у модальному вікні; на сервері — заборона подвійного бронювання (409).
- **Контактна форма** із клієнтською й серверною валідацією.
- **Керування місцями** (`/manage`): додавання й видалення через REST API; захищено токеном адміністратора.
- **Адаптивний дизайн** (360 / 768 / 1280 px), світла й темна теми.
- **Доступність:** skip-link, керування фокусом, ARIA, перевірка клавіатурою.
- **SEO:** унікальні title/description, canonical, Open Graph, JSON-LD (Schema.org), `robots.txt`, `sitemap.xml`.
- **PWA:** маніфест, іконки, service worker, офлайн-сторінка; сайт встановлюється як застосунок.

## Технології
React 19 · Vite · React Router · Node.js · Express 5 · REST API · JSON-сховище · Vitest · React Testing Library · GitHub Actions · Vercel · Render.

## Відомі обмеження
- Дані зберігаються у JSON-файлі; на безкоштовному хостингу вони скидаються після перезапуску сервера.
- Захист `/manage` — простий токен, а не повноцінна авторизація з акаунтами.
- Односторінковий застосунок: частина ботів соцмереж бачить лише початковий `index.html`.
